Neural Tasks – AI & ML Todo

📌 Overview

Neural Tasks is a modern and interactive To-Do List web application designed for AI and Machine Learning students.

It provides a clean productivity workspace where users can add, manage, and track their AI/ML-related tasks while monitoring their completion progress.

✨ Features

- Add new AI/ML tasks
- Track total tasks
- Track completed tasks
- View overall productivity percentage
- Filter tasks by All, Open, and Done
- Organize tasks using categories such as:
  - Machine Learning
  - Python
  - Deep Learning
  - Data Science
- Clean and modern AI-inspired user interface
- Responsive design
- Simple and user-friendly task management

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🎯 Project Purpose

The main purpose of this project is to create a simple productivity workspace specifically focused on AI and Machine Learning students.

It helps users organize their learning tasks and easily monitor their progress.

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in a web browser.
4. Start adding and managing your AI/ML tasks.
